MarkPress

Editor markdown de dos paneles: escribí, previsualizá y exportá a PDF o Writer.

Vista previa
Sintaxis soportada

Markdown estándar y tablas estilo GitHub. LaTeX con $...$ en línea y $$...$$ en bloque. Si una fórmula falla, se muestra el texto original y el detalle queda en la consola.

El botón 🖨️ PDF abre el diálogo de impresión con el documento ya optimizado: elegí "Guardar como PDF" para obtener un PDF vectorial en A4. El borrador se guarda automáticamente en este navegador.

El botón 📝 Writer descarga un .odt listo para abrir y editar en LibreOffice Writer, con formato directo (sin estilos con nombre) y A4. Las fórmulas se convierten a texto con símbolos Unicode y las imágenes quedan como su texto alternativo: en ambos casos el original sigue disponible en el Markdown.
