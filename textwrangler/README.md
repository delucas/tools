# TextWrangler

Domá tu texto sin piedad: ordená líneas (A→Z, Z→A), mezclalas, invertí el orden, quitá duplicadas y líneas vacías, recortá y colapsá espacios, agregá o quitá números a la izquierda, y cambiá entre MAYÚSCULAS, minúsculas, Sentence case y Title Case.

## Uso

1. Pegá tu texto en el editor.
2. Opcional: seleccioná una parte. Sin selección, cada acción aplica a todo el texto; con selección, solo a lo seleccionado (las operaciones de líneas y números expanden la selección a líneas completas).
3. Tocá la acción que quieras. `↩️ Deshacer` revierte la última operación (hasta 50 pasos).
4. Todo se guarda en el navegador. Compartir copia una URL con el texto; Reiniciar vuelve al ejemplo.
