# Diagramas

Dibujá estructuras de datos para tus clases: hoy grafos, pronto árboles y arreglos.

## Uso

1. Escribí el grafo en "✏️ Editar grafo": una arista por línea o separadas por coma (`A-B`, o con costo `A-B:3`). Un nodo aislado se declara solo (`G`).
2. Arrastrá los nodos para acomodarlos; 🎯 reencuadra. El botón ➡️/↔️ cambia entre dirigido y no dirigido.
3. Pintá nodos (p. ej. visitados) con la paleta, o cambiá el trazo de las aristas (normal, punteada, guiones) tocando la arista.
4. Mirá la 🧮 matriz de adyacencia (booleana, o con pesos si hay costos; `∞` = sin arista).
5. Exportá: SVG y PNG (fondo transparente, para apuntes), DOT (Graphviz), PPTX (diapositiva con figuras editables: al mover un nodo, sus aristas lo siguen) o 📋 Excalidraw (copia el JSON al portapapeles para pegarlo directo en excalidraw.com, con las flechas bindeadas a los nodos).

Todo se guarda en el navegador (clave `diagramas`, viaja con el Escritorio). 🔗 Compartir copia un link con el grafo incluido.
