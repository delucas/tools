# Diagramas

Dibujá estructuras de datos para tus clases: grafos y arreglos (árboles, pronto).

## Grafos

1. Escribí el grafo en "✏️ Editar grafo": una arista por línea o separadas por coma (`A-B`, o con costo `A-B:3`). Un nodo aislado se declara solo (`G`).
2. Arrastrá los nodos para acomodarlos; 🎯 reencuadra. El botón ➡️/↔️ cambia entre dirigido y no dirigido.
3. Pintá nodos (p. ej. visitados) con la paleta, o cambiá el trazo de las aristas (normal, punteada, guiones) tocando la arista.
4. Mirá la 🧮 matriz de adyacencia (booleana, o con pesos si hay costos; `∞` = sin arista).
5. Exportá: SVG y PNG (fondo transparente, para apuntes), DOT (Graphviz), PPTX (diapositiva con figuras editables: al mover un nodo, sus aristas lo siguen) o 📋 Excalidraw (copia el JSON al portapapeles para pegarlo directo en excalidraw.com, con las flechas bindeadas a los nodos).

## Arreglos

1. Poné el nombre (opcional, sale arriba) y la lista de valores en el cuadro de texto (separados por coma o por línea) y tocá ▶ Aplicar: se dibuja un rectángulo dividido en celdas iguales, con el valor adentro y el subíndice debajo. Todo en monoespaciada.
2. Pintá celdas con la misma paleta (elegí color y tocá la celda; ✖ lo quita).
3. Agregá 👉 punteros con letra y subíndice (p. ej. la `i` de un `for`): cada uno sale con su color y se dibuja un ⬆ bajo el subíndice con la letra debajo. Arrastrá la flecha para moverla de celda. 🔢 Base cambia el primer subíndice entre 0 y 1.
4. Exportá igual que los grafos: SVG y PNG (fondo transparente; solo las celdas llevan fondo blanco o el color aplicado), PPTX con figuras editables o 📋 Excalidraw (cuadrados nítidos, ⬆ con letra y todo agrupado como un solo diagrama).

Todo se guarda en el navegador (clave `diagramas`, viaja con el Escritorio). 🔗 Compartir copia un link con el diagrama incluido.
