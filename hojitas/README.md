# Hojitas

Generador de hojas A4 para imprimir: puntitos, renglones o cuadrícula, con distancia configurable en milímetros y tres tonos de gris.

## Uso

1. Elegí el tipo de hoja, la distancia en mm (3 a 20) y el tono de gris. En renglones podés sumar la doble raya de margen a la izquierda.
2. Revisá la vista previa y elegí 🖨️ Abrir hoja para ver solo la hoja en una pestaña nueva, lista para imprimir en A4 sin márgenes.
3. La configuración se guarda automáticamente en el navegador. Usá Compartir para copiar una URL con la configuración actual o Reiniciar para volver a la hoja de ejemplo (puntos 5mm).
