# Get Sh*t Done

Lista de tareas hecha con Vue. Cada tarea guarda su fecha de creación y, al tildarla, su fecha de tildado.

## Uso

1. Escribí la tarea y elegí Agregar, o pegá varias líneas para agregar varias tareas a la vez.
2. Tildá con el checkbox para marcarla como completada (se guarda la fecha de tildado); destildá para volver a pendiente.
3. Las completadas quedan debajo, en su propia sección. Arrastrá el control ⠿ para reordenar las pendientes a gusto.
4. Las tres primeras pendientes van en negrita, con una línea divisoria debajo de la tercera. Las pendientes muestran delante un ❗ por cada día desde su creación.
5. Borrá tareas sueltas o todas las completadas con Borrar completadas.
6. El resumen muestra pendientes, completadas hoy y total, con barra de progreso. Solo se guardan fechas, sin hora. Las completadas no se pueden reordenar: van por fecha de tildado, las más nuevas arriba.
5. La lista se guarda automáticamente en el navegador. Usá Compartir para copiar una URL con el estado actual o Reiniciar para recuperar el ejemplo.
