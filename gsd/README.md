# Get Sh*t Done

Listas de tareas hecha con Vue. Cada tarea guarda su fecha de creación y, al tildarla, su fecha de tildado.

## Uso

1. Creá listas nuevas (p. ej. Casa, Trabajo) y cambiá entre ellas en el panel lateral.
2. En la lista activa, escribí la tarea y elegí Agregar, o pegá varias líneas para agregar varias tareas a la vez.
3. Tildá con el checkbox para marcarla como completada (se guarda la fecha de tildado); destildá para volver a pendiente.
4. Las completadas quedan debajo, en su propia sección. Arrastrá el control ⠿ para reordenar las pendientes a gusto.
5. Las tres primeras pendientes van en negrita, con una línea divisoria debajo de la tercera. Las pendientes muestran delante un ❗ por cada día desde su creación.
6. Borrá tareas sueltas o todas las completadas con Borrar completadas. Duplicá o borrá listas enteras desde la tarjeta de la lista.
7. El resumen muestra pendientes, completadas hoy y total de la lista activa, con barra de progreso. Solo se guardan fechas, sin hora. Las completadas no se pueden reordenar: van por fecha de tildado, las más nuevas arriba.
8. Todo se guarda automáticamente en el navegador. Usá Compartir para copiar una URL con todas las listas o Reiniciar para recuperar el ejemplo.
9. Checksmith agrega plantillas como listas nuevas (`?addList=`) sin borrar las existentes. Los links viejos con `?data={tasks}` también se agregan como lista importada.
