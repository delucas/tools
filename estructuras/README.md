# Estructuras

Dibujá matrices, pilas y colas para tus clases con un motor compartido: cada estructura es una especificación (texto + opciones) sobre el mismo canvas, paleta y exports.

## Uso

1. Elegí la pestaña: Matriz o Pila / Cola.
2. Escribí los valores y tocá ▶ Aplicar. En matrices: una fila por línea, columnas separadas por coma. En pila/cola: lista con coma o por línea (en pila el primero es el tope; en cola van de frente a fin).
3. Pintá celdas con la paleta o cambiá el trazo de las flechas tocando la forma.
4. Exportá en SVG, PNG (fondo transparente) o 📋 Excalidraw (cuadrados nítidos, textos atados, todo agrupado) para tus apuntes y diapositivas.
5. Ajustá opciones (nombre, base, índices, orientación) y todo viaja en el link de 🔗 Compartir.

Todo se guarda en el navegador (clave `estructuras`, viaja con el Escritorio).
