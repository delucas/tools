# SVG (se ve ese SVG)

Editor de SVG con vista previa en vivo lado a lado: escribí el código y mirá el resultado al instante.

- Resaltado de sintaxis XML y números de línea (CodeMirror 6).
- La vista previa se actualiza mientras escribís; si hay un error de XML, muestra el detalle y conserva la última vista válida.
- Descarga el dibujo como `.svg` o como `.png` con fondo transparente (escala 1x a 4x).
- Podés abrir un archivo `.svg` existente, compartir tu dibujo con un enlace o reiniciar al ejemplo inicial.
- El borrador se guarda automáticamente en este navegador (clave `svg`).

Todo corre en el navegador, sin backend. Dependencias por CDN: Bootstrap 5 y CodeMirror 6.
