# MarkPress

Editor markdown de dos paneles: escribí a la izquierda, mirá el resultado a la derecha.

## Uso

1. Escribí Markdown (títulos, listas, tablas, código) con LaTeX mezclado: `$...$` en línea y `$$...$$` en bloque.
2. Elegí el estilo del documento: Actual, LaTeX (Latin Modern, justificado) o Tufte.
2. Tocá `🖨️ PDF` para abrir el diálogo de impresión ya optimizado (A4, solo el documento) y elegí "Guardar como PDF".
3. Guardá el fuente con `💾 Guardar` (descarga un `.md`) o abrilo después con `📂 Abrir`.
4. El borrador se guarda automáticamente en este navegador; `🗑️ Reiniciar` vuelve al ejemplo inicial.

Todo corre en el navegador, sin backend. Dependencias por CDN: marked, KaTeX y Bootstrap.
