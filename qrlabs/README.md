# QRlabs

Generador de QR de URL, texto, Wi-Fi y email simple, con tamaño a elección (S/M/L), copiado al portapapeles y descarga en PNG o SVG.

## Uso

1. Elegí el tipo de QR: solo se muestran los campos necesarios (para Wi-Fi: SSID, seguridad, contraseña y red oculta).
2. Completá los datos y elegí el tamaño. El QR se genera al instante en el navegador.
3. Copiá la imagen o descargala como PNG (al tamaño elegido) o SVG (vectorial).
4. Todo se guarda en el navegador. Compartir copia una URL con los datos; Reiniciar vuelve a los valores iniciales.
