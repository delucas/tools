# Wand

Tus bookmarklets en una página, listos para arrastrar a la barra de marcadores y llevar a cualquier computadora.

## Uso

1. Agregá un bookmarklet con nombre, explicación breve y código JavaScript (podés pegarlo con o sin el prefijo `javascript:`).
2. Cada tarjeta muestra el nombre, la explicación y el código oculto en **Ver código**.
3. Arrastrá el botón **★ Arrastrar** hasta la barra de marcadores (mostrala con `Ctrl + Shift + B`). El botón **📋 Código** copia el JS crudo.
4. Los que agregues quedan marcados como **solo en este navegador**. Filtrá por nombre o descripción con el buscador; se pueden editar y borrar.
5. Compartir copia una URL con tus bookmarklets locales para abrirlos en otra máquina. Reiniciar borra los locales.
6. Los fijos viajan con la página: se agregan en `DEFAULT_BOOKMARKLETS` dentro del `index.html`.
