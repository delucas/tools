# Delta

Compará dos textos lado a lado o inspeccioná visualmente un merge de tres. Responde rápido: ¿qué cambió entre estas versiones?

## Uso

1. **Comparar**: pegá o cargá los textos en Origen A y Origen B. Abajo aparecen lado a lado con las diferencias resaltadas (verde = agregado, rojo = eliminado, amarillo = modificado con el cambio exacto marcado).
2. **Mergear**: cargá además el Resultado y elegí `R ↔ A` o `R ↔ B` para ver cómo difiere de cada origen.
3. Navegá con `↑ Anterior` / `↓ Siguiente`; el contador dice cuántas diferencias hay.
4. Cada panel carga `.txt` con 📂 o pega el portapapeles con 📋. 🧹 limpia todo y vuelve al ejemplo.

Todo se guarda en el navegador (clave `delta`, viaja con el Escritorio). Sin Compartir a propósito: los textos suelen ser demasiado grandes para una URL.
