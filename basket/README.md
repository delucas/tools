# Compra-o-matic

Lista de compras para cualquier comercio. Permite cargar productos en bloque, indicar cantidades y unidades, elegir qué comprar y cambiar el orden de la lista.

## Uso

1. Escribí un producto por línea y elegí Cargar lista, o agregá líneas manualmente.
2. Ajustá cantidades, unidades y selección. Arrastrá el control `⠿` para reordenar los productos.
3. La lista se guarda automáticamente en el navegador. Usá Compartir para copiar una URL con el estado actual o Reiniciar para recuperar el ejemplo.
