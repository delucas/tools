# Ducky

Patito de goma para depurar en voz alta: le contás tu problema de código en el chat y, solo con explicarlo, suele aparecer la solución. El patito no responde. Nunca responde.

## Uso

1. Escribíle a Ducky (Enter envía). Todo queda guardado en el navegador.
2. Cuando lo resuelvas, tocá `✦ ¡Lo resolví!`: los mensajes se desvanecen, hay festejo con confeti y el chat se vacía.
3. Compartir copia una URL con solo la frase inicial *"Patito, tengo un problema..."*; Reiniciar vacía el chat y limpia la URL.
