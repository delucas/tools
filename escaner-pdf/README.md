# 📄 Escáner a PDF

Sacá fotos de cada hoja de un examen (o apunte) con la cámara del celu y compilalas en un solo PDF A4 para compartir por WhatsApp, Slack o email.

## Uso

1. Tocá **📷 Iniciar cámara** y permití el acceso.
2. Enfocá cada hoja y tocá **📸 Capturar** por cada página (también podés sumar fotos desde la galería).
3. Reordená arrastrando desde ⠿, rotá con ⟳, recortá con ✂ o borrá con ✕.
4. Escribí el nombre del archivo y tocá **📄 Generar PDF**.
5. Tocá **📤 Compartir** para mandarlo directo a WhatsApp/Slack/email, o **📥 Descargar** para guardarlo.

Todo pasa en tu navegador: las fotos viven solo en la sesión (si recargás se pierden) y el PDF se genera localmente con jsPDF.
