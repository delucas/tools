# EqTeX

Editor de ecuaciones LaTeX con vista previa en fondo blanco, lista para capturar o descargar como PNG transparente.

## Uso

1. Escribí LaTeX en el cuadro de texto y mirá el resultado debajo (render con KaTeX).
2. Elegí el tamaño de la vista previa: 1×, 2× o 3× (se conserva y se comparte).
3. Ponle un nombre y guardá la fórmula en "Mis fórmulas" (se conservan en este navegador).
4. Descargá la vista como PNG con fondo transparente y 1em de margen (`⬇️ Descargar PNG transparente`), copialo al portapapeles (`📋 Copiar PNG transparente`, como en QRLabs) o hacé captura manual (el recuadro siempre es blanco).
4. Compartí una fórmula con `🔗 Compartir` (copia la URL con nombre y código).
5. Exportá la colección a un Markdown legible (`Guardar .md`) o importala desde un archivo (`Abrir .md`).
6. El cheatsheet lateral inserta el comando con un clic en la posición del cursor.

Todo corre en el navegador, sin backend. Dependencias por CDN: Vue 3, KaTeX y html2canvas.
