Sintaxis soportada

Markdown estándar y tablas estilo GitHub. LaTeX con $...$ en línea y $$...$$ en bloque. Si una fórmula falla, se muestra el texto original y el detalle queda en la consola.

El botón 🖨️ PDF abre el diálogo de impresión con el documento ya optimizado: elegí "Guardar como PDF" para obtener un PDF vectorial en A4. El borrador se guarda automáticamente en este navegador.
