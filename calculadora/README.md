# 🧮 Calculadora

Escribí en texto, mirá el resultado en LaTeX.

## Uso

Escribí una expresión (ej: `log2(1024) + 2^10`) y tocá **Enter** o **＝ Guardar** para guardarla en el historial. El resultado se muestra como número y renderizado en LaTeX.

- Funciones: `log2()`, `log10()` (alias `log()`), `sqrt()`.
- Operadores: `+ - * / % ^` (`**` también es potencia), paréntesis, `!` factorial.
- `%` es resto (módulo): `10%3 = 1`.
- `!` solo admite enteros de 0 a 170.
- `ans` vale el último resultado guardado: calculá `2^10`, después escribí `log2(ans)`.
- Acepta coma o punto decimal.

Botones: **∑ Abrir en EqTeX** (lleva la ecuación a EqTeX para exportar el PNG), **📋 Copiar**, **🔗 Compartir** (URL con la expresión).

El historial se guarda en este navegador y sobrevive al recargar.
