# Chromatic

Analizá colores y pequeñas paletas para diapositivas e interfaces: con 1 color muestra ficha y variantes; con 2, contraste WCAG y relación; con 3 o 4, grilla y vista previa de diapositiva.

Todo funciona en el navegador, sin backend. Guardá con 🔗 Compartir o exportá el escritorio desde el índice.
