# Texto grande

Indicaciones silenciosas a la distancia: escribí un mensaje y mostralo a pantalla completa, con letra negra sobre blanco o blanca sobre negro.

## Uso

1. Escribí el mensaje en el cuadro de texto (Enter agrega una línea) o tocá un **mensaje rápido**.
2. Elegí el fondo de la proyección: **⚪ Blanco** (letra negra) o **⚫ Negro** (letra blanca). No cambia el tema claro/oscuro de la interfaz.
3. Dale a **⛶ Pantalla completa** o usá **F11**. En pantalla completa se ve solo el texto, bien centrado.
4. Con el mouse quieto se esconden los controles y el cursor; movelo para que vuelvan. **C** cambia el fondo y **Esc** (o F11) sale de la pantalla completa.
5. **🔗 Compartir** copia un link con el mensaje y el fondo (`?texto=...&fondo=oscuro`). **🗑️ Reiniciar** borra el estado guardado en dos toques.

## Detalles

- El tamaño de letra se calcula solo: busca el mayor cuerpo que entre completo, tanto en ancho como en alto, y se recalcula al escribir, redimensionar, rotar o entrar/salir de pantalla completa. Por eso sirve igual en un proyector 16:9, una TV 4:3 o un celular.
- El texto queda guardado en este navegador; si el link trae un mensaje, no se pisa lo guardado.
- No incluye bloqueo anti-suspensión. Para una proyección larga, revisá el ahorro de energía de la computadora para que no apague la pantalla.
- Abrir el archivo con doble clic (`file://`) funciona igual; la pantalla completa y el portapapeles dependen de lo que permita el navegador.
