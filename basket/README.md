# Compra-o-matic

Listas de compras para cualquier comercio (p. ej. Verdulería, Librería, Ferretería). Permite crear, renombrar y borrar listas, cargar productos en bloque, indicar cantidades y unidades (con pluralización automática: 1 kilo, 2 kilos), elegir qué comprar y cambiar el orden.

## Uso

1. Creá listas con `+ Nueva lista` y renombralas en el campo «Nombre de la lista» (se guarda mientras escribís). También podés escribir un producto por línea y elegir `Agregar a la actual` o `Crear nueva lista`.
2. Ajustá cantidades, unidades y selección. Arrastrá el control `⠿` para reordenar los productos.
3. La lista se guarda automáticamente en el navegador. Usá Compartir para copiar una URL con todas las listas o Reiniciar para recuperar el ejemplo.
