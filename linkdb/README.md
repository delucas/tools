# LinkDB

Tus links favoritos en una página, accesible desde cualquier navegador. Incluye links fijos y permite sumar los propios en cada dispositivo.

## Uso

1. Pegá una URL y elegí Agregar: el título se obtiene automáticamente (Microlink, con un proxy como respaldo) y lo podés corregir antes de guardar.
2. Los links que agregues quedan marcados como **solo en este navegador**: se guardan localmente y se pierden si cambiás de navegador o borrás sus datos.
3. Filtrá por título o URL con el buscador. Los links propios se pueden editar y borrar; los fijos no se tocan.
4. Compartir copia una URL con tus links locales para llevarlos a otro navegador. Reiniciar borra los links locales.
