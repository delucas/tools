# 📌 Board

Mini Trello minimalista: columnas y tarjetas arrastrables.

## Uso

Agregá columnas con **+ Agregar** o cargá una **plantilla** (Kanban, Scrum, Daki o Vacío; cargar reemplaza todo el tablero con doble toque).

- En cada columna, escribí al pie y tocá `+` (o Enter) para agregar tarjetas.
- Arrastrá tarjetas entre columnas y columnas entre sí (manijas `⠿`).
- Doble-click o `✏️` abre la tarjeta: título + explicación en texto plano. Las tarjetas con explicación muestran `📝`.
- Click en el título de una columna lo renombra; `🧹` vacía la columna y `×` borra (tarjetas y columnas piden doble toque).
- **JSON ⬇️ / MD ⬇️** exportan el tablero (el Markdown se pega en MarkPress); **📥 Importar** lo restaura desde un JSON.

Todo se guarda en este navegador y sobrevive al recargar.
