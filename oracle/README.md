# Oracle

La clásica bola 8 mágica en español: escribí tu pregunta y agitá la bola (o presioná Enter) para recibir una de sus 20 respuestas clásicas, cada una con la misma probabilidad.

## Uso

1. Abrir `index.html`.
2. Escribir una pregunta (opcional: también responde sin pregunta).
3. Pulsar "🎱 Agitar" o presionar Enter y esperar la respuesta.
4. Con "🔗 Compartir" se copia un link con la pregunta y la respuesta obtenida, para reírse en compañía.
