# Clippy

Inspector de portapapeles: pegá algo y mirá qué hay adentro.

## Uso

- Tocá **📋 Leer portapapeles** (pide permiso al navegador) o pegá con **Ctrl+V** en cualquier parte.
- En el celu, usá el cuadro de pegado manual (mantené presionado → Pegar).
- Muestra todos los formatos disponibles: texto plano, HTML (código + vista renderizada aislada) e imágenes (vista previa + dimensiones).
- Incluye estadísticas (caracteres, palabras, líneas, tamaño) y botones para copiar de vuelta o descargar cada formato.
- Si lo pegado es un SVG (imagen o código), ofrece abrirlo en 👁️ SVG para editarlo.
- Privado: todo se procesa en el navegador, nada se guarda; al recargar se pierde.
