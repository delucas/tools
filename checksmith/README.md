# Checksmith

Forja de checklists hecha con Vue. Guarda un catálogo de plantillas con nombre e ítems, y las instancia como lista pendiente en Get Sh*t Done mediante un link.

## Uso

1. Creá una plantilla con nombre, o duplicá una existente para variar.
2. Agregá ítems de a uno o pegando varias líneas. Arrastrá el control ⠿ para ordenarlos.
3. Elegí ✅ Usar en GSD para agregar la plantilla como lista nueva (con fecha de hoy) en Get Sh*t Done, o 🔗 Copiar link GSD para compartirla. No borra las listas existentes.
4. El catálogo se guarda automáticamente en el navegador. Usá Compartir para copiar una URL con todas las plantillas o Reiniciar para recuperar los ejemplos.
