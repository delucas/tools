# Delta

Compará dos textos lado a lado y respondé rápido: ¿qué cambió entre estas versiones?

## Uso

1. Pegá o cargá los textos en Origen A y Origen B. Abajo aparecen lado a lado con las diferencias resaltadas (verde = agregado, rojo = eliminado, amarillo = modificado con el cambio exacto marcado).
2. Navegá con `↑ Anterior` / `↓ Siguiente`; el contador dice cuántas diferencias hay.
3. Cada panel carga `.txt` con 📂 o pega el portapapeles con 📋. 🧹 limpia todo.
4. ¿Necesitás combinar versiones en vez de compararlas? Para mergear usá una herramienta externa como [DiffResolver](https://diffresolver.com).

Todo se guarda en el navegador (clave `delta`, viaja con el Escritorio). Sin Compartir a propósito: los textos suelen ser demasiado grandes para una URL.
