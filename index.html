🧰 Herramientas

por Lucas Videla (@delucas)

Colección de herramientas minimalistas: gratis, sin cuentas, sin backend ni tracking. Cada una es una página autocontenida que corre entera en tu navegador.

🕐 Clocks... assemble!
Reloj mundial para trackear la hora de tu equipo o contactos. → ✔ Tablas de Verdad
Generador de tablas de verdad a partir de una expresión booleana. → 📊 CSV a Gráfico
Convierte un CSV pegado en un gráfico de torta, series o líneas. → ⌨ PSEditor
Editor de pseudocódigo con resaltado, indentación y operadores Unicode. → 🛒 Compra-o-matic
Lista de compras, con cantidades y orden personalizado. → ✅ Get Sh*t Done
Lista de tareas con fecha de creación y fecha de tildado. → ⚒️ Checksmith
Forja de checklists: plantillas para instanciar en Get Sh*t Done. → 📄 Hojitas
Hojas A4 para imprimir: puntitos, renglones o cuadrícula. → ∑ EqTeX
Editor de ecuaciones LaTeX con vista previa y PNG transparente. → 📰 MarkPress
Editor markdown de dos paneles con tablas, LaTeX y salida a PDF. →
