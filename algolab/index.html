🃏 AlgoLab

Mesa virtual para enseñar algoritmos con cartas, fichas y fibrones.

🃏 Cartas

Sin repetición no salen cartas iguales entre sí ni repetidas de la mesa. El comodín viene de a uno por pedido y no se agota nunca.

🎰 Fichas

Color aleatorio. Sirven como marcadores o punteros.

🖊️ Fibrones

Color aleatorio. Son objetos para separar o marcar, no dibujan.

Mesa

Mesa vacía
La mesa está vacía.
Agregá cartas, fichas o fibrones desde el panel.
🗑️
Descarte

Arrastrá con el dedo o el mouse para mover. Lo que movés pasa al frente. Con ⛶ la mesa ocupa toda la pantalla (F11 es del navegador y no se puede usar para esto). Acercá con + o Ctrl+rueda y recorré la mesa arrastrando el paño vacío o con la ruedita apretada. Doble clic en una carta (o Enter con el teclado) la voltea; doble clic en el paño voltea todas; doble clic en un fibrón lo rota 90°. Arrastrá al 🗑️ Descarte para quitar objetos (o Supr con el teclado).
